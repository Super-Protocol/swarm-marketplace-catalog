Every `/v1` request needs `Authorization: Bearer <the key>`. `/health` does not,
which is why it is the probe; it is also why the ingress publishes `/v1` alone
and leaves `/metrics` and `/docs` inside the cluster space.
{{- if $e.shared }}

The {{ len $e.engines }} engines above share one card, in one container, with the share of its
memory each one claims written into the deployment's evidence. Each has its own
base URL — the prefix is what tells them apart — and all of them answer to the
same key.
{{- end }}

The first start downloads the weights and hashes them. That is minutes, and the
pod is not ready until {{ if $e.shared }}every engine has{{ else }}the engine has{{ end }} loaded them and compiled its graphs.
