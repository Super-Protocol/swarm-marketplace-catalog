# Harbor Point Gastroenterology — Colonoscopy Surveillance (US)

A synthetic two-site academic US gastroenterology practice: 3,400 patients, a record that begins
in June 2022 because the practice does, and the highest adenoma detection rate of the three
clinic networks on this catalogue — **45%**, which is where the top decile of endoscopists sits.

Everything here is generated by `datasets/gi-network-generator/` (`--network harbor-point`). No
row, no name and no sentence is taken from a real patient, a real practice or a real dataset, or
derived from one. The generator is deterministic, so a regenerated copy is the same data, not
similar data.

It is one of three cards built on the same generator and the same schema. The shared material —
why the structured tables and the free-text documents are deliberately not redundant, why the
data is identifying on purpose, why `access.mode: gateway` is load-bearing rather than
decorative, what each table holds and which four column descriptions earn their length — is
written once, in `datasets/cypressbay-digestive-health/README.md`, and applies here unchanged
with `cbdh_` read as `hpg_`.

## What is different about this one

It is the **small, recent, completely captured** network, and each of those is a deliberate
choice rather than a smaller copy.

| | |
|---|---:|
| Sites | 2 (5 and 2 endoscopy suites) |
| Patients | 3,400 |
| Record begins | 2022-06-13 |
| Procedures per patient | 1.6 — an academic practice scopes the patients it has more often |
| Adenoma detection rate, screening colonoscopies | **45.3%** |
| Mean withdrawal time | 13.1 minutes |
| Examinations with no bowel-preparation score | **none** |
| Colonoscopies with no withdrawal time | **none** |
| Surveillance intervals missing from the record | **none** |
| Capture lag | none — the record runs to the as-of date |
| Tables | `hpg_*` in `marketplace` |

**Nothing has to be excluded from a denominator here.** That is the whole reason this corpus
exists beside the other two: a figure computed over it is computed over every examination, so it
is the comparator that makes the coverage caveats of a network with an incomplete record legible
rather than theoretical. A question that produces one number per network — a detection rate, a
mean withdrawal time, surveillance adherence — gets an uncomplicated answer from this practice
and a heavily qualified one from `ridgeline-endoscopy`, and the difference between those two
kinds of answer is as much the demonstration as the numbers are.

The high detection rate is not a compliment paid to invented doctors. It is what gives the
cross-network comparison a spread to find, and it is capped in the middle forties on purpose: a
synthetic practice finding adenomas in half of everybody it scopes is a number a
gastroenterologist stops reading at.

## Generating and loading

```bash
cd generate
./generate.py --out ./out              # 3,400 patients, ~50,000 rows, 44 documents
```

```bash
cd out
CH_URL=http://10.10.1.11:8123 CH_USER=<owner> CH_PASSWORD=<secret> ./load.sh
```

The schema drops and recreates every table, so a reload replaces the corpus rather than doubling
it. The documents under `notes/` are uploaded to the application by hand — they are files a
clinician reads, not a table.

Checks:

```bash
cd ../../gi-network-generator
./selftest.py --network harbor-point
./selftest.py --all-networks           # after any change to the shared generator
```

## Access

Restricted. Synthetic demonstration data: it may be loaded, queried and shown freely, and it
carries no patient confidentiality obligation because there is no patient. It is not a
substitute for real data in any evaluation that claims clinical validity.

The reader account behind this card's secrets must be `readonly = 2`, not `readonly = 1`, for the
reason set out at the end of `datasets/cypressbay-digestive-health/README.md` — a client that
sends per-query limits is a client that changes settings, and under `readonly = 1` every question
the agent asks comes back as a `READONLY` exception with nothing in the UI to say why.
